# Official and Open Learning Resources

These are **reference sources**, not replacement exercises. Read a concept here, then build and test the corresponding academy lab. Licensing differs per upstream project; do not copy whole books or third-party tutorials into this repository.

## Foundations
- Python tutorial: https://docs.python.org/3/tutorial/
- Python unittest: https://docs.python.org/3/library/unittest.html
- SQLite documentation: https://www.sqlite.org/docs.html
- PostgreSQL manual: https://www.postgresql.org/docs/
- Linux command-line documentation: https://www.gnu.org/software/coreutils/manual/
- Git book (free): https://git-scm.com/book/en/v2
