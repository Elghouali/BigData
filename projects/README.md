# Big Data & Cloud Computing — Hands-on Portfolio Labs

Independent reference projects to **run, understand, and rebuild by hand**, separate from the original university coursework.

| Project | Skills | Level |
| --- | --- | --- |
| [Retail PySpark Lakehouse](retail-pyspark-lakehouse/) | Data quality, Spark, Parquet, Bronze/Silver/Gold | Intermediate |
| [Cloud Object Storage API](cloud-object-store-api/) | FastAPI, S3 API, Docker, Terraform, cloud security | Intermediate |

**Learning method:** Run the reference implementation → create your own branch → reimplement it without copying → test and compare → open a pull request.

The default labs are local and do not require a paid cloud account. Cloud infrastructure files are examples only; never apply Terraform without reviewing resource costs and access policies.
